# Production website

This folder is the generated React + Vite + TypeScript website. Source code and build instructions are in `../site/README.md` in the full repository.

Serve this directory with any static web server, or use GitHub Pages with your branch's `/docs` folder as the publishing source. Asset paths are relative, so project subdirectories work. No backend or API key is required.

Do not edit generated JavaScript or CSS. Edit `site/src/` and run `npm run build` from `site/` instead.
